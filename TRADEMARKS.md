Sifthound's code is open source under the [MIT License](LICENSE). You can use, modify, host
and sell it. The **name "Sifthound"** and any Sifthound logos are trademarks of the project's
maintainer ([@khsarvar](https://github.com/khsarvar)), and the MIT License doesn't grant rights
to them.

This policy exists so that people can tell whether they're using the official project. It
isn't meant to restrict what you do with the code.

## You can, without asking

- Say truthfully that your product uses, works with, or is based on Sifthound, for example
  "built on Sifthound" or "a fork of Sifthound".
- Redistribute **unmodified** Sifthound releases under the Sifthound name.
- Write articles, tutorials, videos, talks and comparisons that mention Sifthound.
- Use the name for non-commercial community groups and events, as long as they don't suggest
  they're run or endorsed by the project.

## Please ask first

- Naming a product, service, company, package or hosted API "Sifthound", or anything
  confusingly similar (such as "Sifthound Cloud" or "SiftHound Pro").
- Distributing a **modified** version under the Sifthound name. Forks should use a different
  name; "based on Sifthound" is fine.
- Using "Sifthound" in a domain name, or using a Sifthound logo in a way that suggests the
  project endorses or partners with you.

## Questions and permission

Open an issue at <https://github.com/khsarvar/sifthound/issues> or contact
[@khsarvar](https://github.com/khsarvar). If you're unsure whether something is allowed, ask;
reasonable requests are usually approved.
