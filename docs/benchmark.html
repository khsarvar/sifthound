Sifthound vs Tavily: search benchmark

25 September 2026 · Sifthound 0.2.1 · 45 queries

  • Facts: on par. Both found 25 of 25 answers in advanced mode.
  • Official docs: Sifthound found them more often, 9 of 10 vs Tavily's 7 (basic) and 3 (advanced).
  • Speed: similar. Tavily was faster in basic mode, Sifthound in advanced.
  • Cost: $0 per search, vs $8–16 per 1,000 on Tavily.

Highlighted: better within each mode. Sifthound's cost excludes its server. Tavily's is pay-as-you-go ($0.008 per credit).

Method

  • Both called through the official tavily-python client with identical arguments; only the base URL differed.
  • 45 queries: 25 factual questions with a known answer, 10 technical questions with an official docs site, 5 news, 5 open-ended. 5 results each, basic and advanced.

Caveats

  • Some of Sifthound's search engines (Google, Google CSE, Brave) were rate-limiting the test machine, so these numbers aren't Sifthound at full strength.
  • Small sample: a difference of one or two queries isn't significant.
  • Sifthound ran locally; Tavily over the internet.
  • A single run on 25 September 2026. Results change over time.

Reproduce it

pip install -r bench/requirements.txt
docker compose up -d
TAVILY_API_KEY=tvly-... python bench/run.py --delay 6
python bench/report.py bench/results/<timestamp>

Code and queries: bench/. A full run uses about 135 Tavily credits.
